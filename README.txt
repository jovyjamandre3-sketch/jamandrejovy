Jovy A. Jamandre Portfolio

HOW TO USE
1. Extract this ZIP file.
2. Open the jovy_portfolio folder in VS Code.
3. Add four images to the images folder named:
   picture1.jpg, picture2.jpg, picture3.jpg, picture4.jpg
4. Open index.html with Live Server.

Your uploaded portrait is included as images/profile.jpg.
The gallery is designed as a responsive 2 x 2 grid.
The contact form validates the fields but needs a backend or form service to actually send messages.
